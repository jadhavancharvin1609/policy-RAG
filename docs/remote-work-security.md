# Remote work and security policy

## Approved working locations
Employees may work remotely from approved locations in the country of employment. International remote work requires written People Operations approval before travel.

## Secure access
Use company-managed devices whenever possible. Enable multi-factor authentication and use the company VPN before accessing internal systems from an untrusted network. Do not share passwords or copy confidential files to personal storage.

## Reporting incidents
Report a lost device, suspicious email, or possible data exposure to the Security team immediately through the incident portal. Do not investigate suspected malware yourself.
